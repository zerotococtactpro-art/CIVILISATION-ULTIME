# Configuration Pterodactyl

Cette version force les joueurs vers le monde `hub` au join.

Tu peux garder :
- `world` = monde RP
- `hub` = monde Hub

Ne supprime pas `global`.

Si ton panel possède un champ `LEVEL` / `level-name`, ne le change pas sans vérifier la configuration du serveur : le plugin assure déjà la téléportation d'arrivée.

Pour que `hub` soit aussi le monde initial généré par Minecraft lui-même, une configuration serveur séparée peut être nécessaire selon l'egg/Pterodactyl utilisé. Cette version ne modifie pas automatiquement `server.properties` afin de ne pas casser ta configuration existante.
